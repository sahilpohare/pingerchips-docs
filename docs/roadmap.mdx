# Pingerchips Roadmap

## Completed ✅

### 2023-2024

- ✅ Stabilized release and launched v1.0
- ✅ Phoenix/Elixir-based queue processor
- ✅ Real-time WebSocket messaging
- ✅ Public, private, and presence channels
- ✅ Pingerflows (Filter, Transform, Schema Validator, Throttle, Debounce, Delay, Send to Channel nodes)
- ✅ JavaScript/Node.js SDKs
- ✅ Pusher compatibility
- ✅ mTLS support for production
- ✅ Dashboard for app management

## In Progress 🚧

### Q4 2024 - Q1 2025

- 🚧 Enhanced analytics and metrics
- 🚧 Improved flow editor UI/UX
- 🚧 Additional SDK languages (Python, Go, PHP)
- 🚧 Webhook support for event delivery
- 🚧 Advanced rate limiting controls

## Planned 📋

### 2025 Q1-Q2

- Branch node for conditional workflow routing
- Join node for workflow merging
- Kafka integration node
- Message replay and history
- Custom domain support

### 2025 Q2-Q3

- Apache Spark job triggers
- Stream processing pipelines
- GraphQL subscription support
- Enhanced presence features (typing indicators, user metadata)
- Multi-region deployment

### Future

- **Pingercritter IoT** - MQTT protocol support for IoT devices
- Edge computing support
- Advanced security features (IP whitelisting, custom auth)
- Workflow templates marketplace
